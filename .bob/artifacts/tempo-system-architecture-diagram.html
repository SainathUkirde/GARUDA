Key Runtime Flow — Disruption → Re-plan
🔄 Disruption → Diff → Accept / Reject Loop
Event injected → scenario state updated → CP-SAT re-optimise → 500-run Monte Carlo → BEFORE → AFTER diff → Commander: ACCEPT / REJECT
  • Disruption types: AIRCRAFT_UNSERVICEABLE · CREW_UNAVAILABLE · WEATHER_CLOSING · NEW_THREAT · COMMS_JAM · PRIORITY_CHANGE
  • NL commands (voice or typed) map to the same DisruptionEvent type via NL parser
  • CONTESTED mode adds LOW CONF tags to assignments; per-source confidence & data-age shown
  • Human-in-the-loop: nothing commits until ACCEPT pressed (keyboard shortcut A)
